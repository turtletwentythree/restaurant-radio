# วิทยุร้าน — Restaurant Radio

เว็บแอปเล่นเพลงพื้นหลังสำหรับร้านอาหาร ออกแบบให้เปิดจาก Safari บน iPhone
เพลย์ลิสต์แบ่งตามเทศกาล (สงกรานต์ ลอยกระทง คริสต์มาส ปีใหม่ ฯลฯ) เลือกเล่นเองได้ตามต้องการ

## ไฟล์ในโปรเจกต์นี้

- `index.html` — ตัวแอปทั้งหมด (HTML/CSS/JS ไฟล์เดียว) เปิดใช้งานได้ทันทีจาก URL ที่ publish ไว้
- `supabase/schema.sql` — SQL ตั้งต้นสำหรับสร้างตาราง + storage bucket บน Supabase project ใหม่
- `supabase/functions/music-api/index.ts` — Supabase Edge Function ที่เป็น backend คลังเพลง (deploy ผ่าน Supabase MCP หรือ Supabase CLI)

## สถาปัตยกรรมโดยย่อ

เพลง (ไฟล์เสียงจริง) และข้อมูลเพลย์ลิสต์ทั้งหมด **เก็บอยู่บน Supabase คลาวด์** ไม่ได้เก็บในเบราว์เซอร์เครื่องเดียวอีกต่อไป:

- ไฟล์เพลงเก็บใน Supabase Storage bucket ชื่อ `songs` ซึ่ง**ตั้งเป็น private** (ไม่ public) — ป้องกันไม่ให้ไฟล์เพลงที่มีลิขสิทธิ์หลุดออกสู่สาธารณะ
- ข้อมูลเพลย์ลิสต์/ชื่อเพลง/การตั้งค่า เก็บเป็น JSON ในตาราง `shop_data` (แถวเดียวต่อร้าน)
- การเข้าถึงทั้งหมดต้องผ่าน **Edge Function (`music-api`)** ซึ่งเช็ค "รหัสผ่านคลังเพลง" ของร้านก่อนทุกครั้ง แล้วจึงสร้าง signed URL อายุสั้น (1 ชั่วโมง) ให้เล่นเพลงได้ — ไม่มีใครเข้าถึงไฟล์เพลงได้โดยไม่รู้รหัสผ่าน
- เปิดลิงก์แอปจากเครื่องไหนก็ได้ ใส่รหัสผ่านคลังเพลงเดียวกัน ก็จะเห็นเพลย์ลิสต์และเพลงชุดเดียวกันทันที (แก้ปัญหาเดิมที่เปิดจากเครื่องอื่นแล้วเพลงหาย)

## ตั้งค่า Supabase backend ใหม่ (ถ้าต้องย้ายไปโปรเจกต์อื่น)

1. สร้าง Supabase project ใหม่
2. รัน `supabase/schema.sql` กับ project นั้น (สร้าง bucket `songs` แบบ private + ตาราง `shop_data`)
3. Deploy `supabase/functions/music-api/index.ts` เป็น Edge Function ชื่อ `music-api` (ตั้ง `verify_jwt = false` เพราะแอปใช้ระบบรหัสผ่านของตัวเอง ไม่ใช้ Supabase Auth)
4. แก้ค่า `API_BASE` ใน `index.html` ให้ชี้ไปที่ URL ของ Edge Function ใหม่ (รูปแบบ `https://<project-ref>.supabase.co/functions/v1/music-api`)

ไม่ต้องตั้งค่า secret เพิ่มเติมใดๆ — `SUPABASE_URL` และ `SUPABASE_SERVICE_ROLE_KEY` ถูกฉีดให้อัตโนมัติโดย Supabase Edge Runtime

## รหัสผ่านคลังเพลง

ครั้งแรกที่เปิดแอป ระบบจะให้ตั้ง "รหัสผ่านคลังเพลง" (อย่างน้อย 4 ตัวอักษร) — ใครก็ตามที่รู้รหัสผ่านนี้และเปิดลิงก์แอป จะเห็น/แก้ไขคลังเพลงเดียวกันได้ เปลี่ยนรหัสผ่านได้ภายหลังจากหน้า "ตั้งค่า" ในแอป
